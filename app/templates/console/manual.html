Calloway Admin Console

The complete guide to every screen, button, and feature in the admin console.

Table of Contents Login Sidebar Navigation Dashboard Tenants Conversations Triggers Errors Costs Health Harness Tips & Shortcuts

Login

Enter the console password (set via the CONSOLE_PASSWORD environment variable) and click Sign In. Sessions last 24 hours before you're redirected back to login.

Health Status Dot (top-right corner): A colored dot that auto-refreshes every 30 seconds. Green = all systems healthy, Yellow = degraded, Red = critical issue.

Recent Activity (left panel)

A live feed of the most recent messages across all tenants. Auto-refreshes every 15 seconds. Each entry shows the timestamp, agent name, sender badge (green for client, blue for AI, gray for system), message preview, and contact name.

Needs Attention (right panel)

Flags tenants needing manual intervention:

  • Errors — Tenants with errors in the last 24 hours. Click the name to investigate.
  • Inactive 48h+ — Tenants with no activity for 48+ hours. May indicate a Twilio issue.
  • All clear — Shown when no tenants need attention.

New Tenant

Form to register a new real estate agent. Fields marked * are required.

Agent Profile

  • Name* — Full name of the real estate agent
  • Email* — Email address for notifications
  • Phone* — Personal phone in E.164 format (e.g. +15551234567)
  • Brokerage — Brokerage firm name
  • Market — Primary geographic area
  • Timezone — Used for scheduling triggers and daily briefings

Twilio Configuration

  • Twilio Phone Number* — The Twilio number contacts will text. Must be provisioned in Twilio first.

Style & Autonomy

  • Tone — Professional, Friendly, or Casual
  • Emoji Usage — Whether the AI should include emojis
  • Autonomy Level:
    • Supervised — AI drafts messages, agent approves before sending
    • Autonomous — AI sends messages directly without approval
    • Manual — AI only responds when explicitly prompted
  • Buffer Minutes — Minimum minutes between showings for travel time (default: 30)

Optional

  • Google Review Link — URL to the agent's Google Business review page
  • Briefing Time — Time of day for the daily briefing summary (default: 07:30)
  • System Prompt Override — Custom system prompt that overrides the default AI instructions

Tenant Detail

Full profile view for a single tenant. Action buttons at the top:

ButtonWhat It Does
Edit ConfigOpens the edit form to change profile, tone, autonomy, etc.
Test SMSSends a test SMS to verify Twilio is working
DeactivateDisables the tenant — stops all AI responses and scheduled triggers. Requires confirmation.

The left panel shows Profile, expandable Configuration (Style Profile, Autonomy Rules, Scheduling Prefs, Raw JSON), and Recent Messages (last 20).

The right sidebar shows This Month stats (cost, messages, errors), Contacts (with lifecycle stage and consent badges), Listings, and Pending Triggers.

A red revoked badge on a contact means TCPA consent was revoked — no automated messages allowed.

Conversations

Filters

  • Agent — Filter by tenant
  • Channel — SMS, RCS, Vapi (voice), or Email
  • Search — Contact name or phone number

Conversation Detail

Click a contact name to view the full chat thread:

  • Green messages — Inbound from the contact
  • Blue messages — AI-generated responses
  • Gray messages — System messages

Each message shows metadata: sender type, LLM model used, token count, detected intent, feedback score, and timestamp.

Tool execution blocks appear inline as expandable sections. Click to see tool name, status, input/output JSON, error message, and latency.

The right sidebar shows Contact info (name, phone, role, lifecycle stage) and Active Triggers for this conversation.

Triggers

Triggers are scheduled actions the AI creates (follow-ups, review requests, briefings, etc.).

Filters

  • Status — Pending, Completed, Error, Cancelled, or All
  • Agent — Filter by tenant

Errors

Filter by Agent to narrow down errors to a specific tenant.

Tool Execution Errors

Failures from external tool calls (calendar, MLS, CRM, etc.). Click the error summary to expand and see full error message, input JSON, output JSON, and latency.

Application Errors

Internal system errors and warnings. Severity badges: error = requires investigation, warning = non-critical. Click to expand the full message and stack trace.

Pipeline Performance (24h)

  • p50 — Median latency (50% of requests are faster)

Manual Actions

Run Scan — Select a tenant and click Run Scan to trigger the daily scan immediately. This checks contacts, triggers, and health metrics for that agent.

Harness

The Test Harness is a separate tool for simulating conversations. Use it to test how the AI responds to various scenarios without involving real contacts or Twilio.

Tips & Shortcuts

  • Hover any element for a tooltip explaining what it does
  • Click triangles (<details>) to expand configuration, errors, or tool executions
  • Use browser back/forward to navigate between pages
  • Dashboard and Health pages use HTMX for live updates — no manual refresh needed
  • Sessions expire after 24 hours — you'll be redirected to login automatically
  • The password is set via CONSOLE_PASSWORD env var — change it in Railway for production use
